Privacy Policy — GW2 Leggy

Last updated: August 16, 2026
Application: GW2 Leggy (com.gw2leggy.app)

GW2 Leggy is an unofficial fan-made application and is not affiliated with, endorsed by, or sponsored by NCSoft Corporation or ArenaNet, LLC.

This Privacy Policy describes how the GW2 Leggy mobile application (“the App”) handles information.

Summary

  • We do not operate user accounts for GW2 Leggy.
  • We do not collect analytics, advertising IDs, or crash reports through third-party SDKs in the App.
  • Your Guild Wars 2 API key (if entered) is stored on your device and sent only to ArenaNet’s official API at https://api.guildwars2.com.
  • Favorites and crafting checklist progress are stored on your device.

Information the App uses

Information you provide

Guild Wars 2 API key (optional). If you paste an API key, it is saved in the app’s local storage on your device and used only to request account-related data from the official Guild Wars 2 API (Legendary Armory, bank/stash, characters, wallet, Wizard’s Vault, and similar).

Information stored on device

  • API key (if saved)
  • Favorite / pinned legendary IDs
  • Manual crafting checklist state
  • Cached UI state needed for normal operation

This data remains on your device until you clear app storage or uninstall the App.

Information obtained from ArenaNet

When you use an API key, the App requests data from https://api.guildwars2.com. That data is processed on your device. The App does not upload it to GW2 Leggy servers — there are no GW2 Leggy backend servers.

Technical / network data

The App requires network access to call the Guild Wars 2 API and load item icons. Your device and network provider may process standard connection metadata as part of HTTPS traffic. The App developer does not receive that traffic.

How information is used

  • To display legendary progress, stash, vault, and related features
  • To validate your API key against the official API
  • To remember preferences on the device

Sharing

  • ArenaNet / Guild Wars 2 API: API key and requests go to ArenaNet when you use authenticated features.
  • No sale of personal data.
  • No advertising partners and no analytics SDKs in the App.

Retention

Local data remains until you remove the API key in-app, clear app storage, or uninstall. The developer does not retain your API key or account data on remote servers.

Children’s privacy

The App is not directed at children under 13 (or the minimum age required in your country). Do not provide an API key if you are not permitted to use Guild Wars 2 / ArenaNet services.

Security

API keys are stored in the WebView’s local storage. Protect your device and treat your ArenaNet API key like a password. Revoke keys anytime at account.arena.net/applications.

Your choices

  • Use the App without an API key
  • Remove the saved key in the App
  • Clear app storage or uninstall
  • Revoke the key on ArenaNet’s site

Third-party services

  • Guild Wars 2 API — https://api.guildwars2.com
  • ArenaNet / Guild Wars 2 item icon and render URLs

Changes

This policy may be updated when data practices change. The “Last updated” date will be revised.
